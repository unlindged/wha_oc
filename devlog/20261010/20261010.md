## #2 Reconfigure circuit to control LED brightness instead of color

Found out that this wasn't a direct hardware change, but a software change. Not that involved either, it was pretty much just:

### Before
```
if(val < 0b000000){
    val = 0b000000;
}
if(val > 0b001110){
    val = 0b001110;
}

PORTB = val;
```
### After
```
if(val < 0){
    val = 0;
}
if(val > 255){
    val = 255;
}

analogWrite(redpin, val);
analogWrite(greenpin, val);
analogWrite(bluepin, val);
```
