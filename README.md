# Witch Hat Atelier OC Costume Project
This is a repo that contains the software, firmware, and hardware details for a Witch Hat Atelier original character cosplay. This overall README will be updated as project elements are completed.

Devlog for the project can be found here.

## The Costume
The costume itself consists of three main objects:
* [The Cap](https://github.com/unlindged/wha_oc/tree/main/hat)
* The Palm Quire
* The Cloak

These three objects are meant to function together as kind of a a little "Internet of Things" project with the palm quire as its "control center". Each object has its own folder with specific details about its design and implementation.
